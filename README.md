
# Geometry Calculator Web Page

## Project Description

The Geometry Calculator Web Page is developed using HTML, CSS, and JavaScript. The application calculates the area of a rectangle and a circle based on user input. It also includes a Type and Comparison Tester to demonstrate JavaScript data types, type conversion, and comparison operators.

## Approach

- Used HTML to create the input fields, dropdown, and buttons.
- Used CSS to style and align the webpage elements.
- Used JavaScript to calculate areas, validate inputs, and display results.
- Added a Type and Comparison Tester to check data types and compare values.

## Learnings

- Practised `let`, `const`, and JavaScript data types.
- Learned arithmetic and comparison operators.
- Practised explicit and implicit type conversion.
- Learned DOM manipulation and event handling.
- Understood primitive and reference types.
- Practised input validation and template literals.

   ##  Working Procedure
1. The user selects a shape from the dropdown menu.
2. The corresponding input fields are displayed.
3. The user enters the required dimensions.
4. JavaScript validates the inputs and calculates the area.
5. The calculated result and shape details are displayed on the webpage.
6. In the Type and Comparison Tester, the user enters two values to explore their types and comparison behavior.
